# 0.5.0 — 2026-11-13

## Added

- **`cisa_search_ics_advisories`** indexes originating vendor advisory summaries and returns distinct summary and URL pairs, including separate CSAF and HTML links. The tool qualifies search misses while an existing mirror re-ingests the new fields. ([#60](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/60))
- **`cisa_get_alerts`** accepts `detail: "full"` to expand capped descriptions for items without an advisory ID, preserving literal text in Markdown. For capped items with an ID, it returns the advisory lookup to use. ([#61](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/61))

## Changed

- **KEV and ICS vendor and product filters** trim surrounding whitespace before matching and require at least two characters after trimming. Previously accepted padded one-character terms are rejected. ([#58](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/58))

## Removed

- **`cisa_get_ssvc`** omits `assignmentAgrees` unless the KEV entry explicitly cites BOD 26-04. The computed timeline and assigned due date remain available separately. ([#59](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/59))
- **Resource list entries** omit generic `title` fields so clients display each record's distinct name. ([#63](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/63))

## Fixed

- **Advisory vulnerability entries** preserve reference summaries and URLs verbatim in structured output and render HTTP(S) references as Markdown links. A single distinct FIRST calculator vector is exposed as `cvssV4Vector` alongside the published scores. ([#57](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/57))
- **KEV deadline and RSS coverage descriptions** explain that historical deadline gaps vary and direct callers to `window.oldest` and `window.newest` for feed coverage. ([#62](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/62))

## Dependencies

- `better-sqlite3` ^13.0.3 → ^13.1.1
- `@biomejs/biome` 2.6.6 → 2.6.7
