# 0.4.1 — 2026-11-11

## Added

- **`cisa_search_kev`** accepts `detail: "summary"` for the eleven triage fields shared with CVE status. Full records are the default, and each cursor request chooses its own detail ([#52](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/52)).

## Changed

- **CISA cybersecurity guide 1.1** clarifies when to retain both exposure branches and how to report computed timelines alongside assigned due dates.
- **Bun** minimum version is 1.4.4.
- **Framework adoption** adds explicit KEV and advisory resource titles, documents JWT audience and issuer settings, and keeps the local advisory sync lease alongside framework write fencing.

## Fixed

- **SSVC assignment agreement** compares both the remediation day count and forensic-triage requirement when both timelines are available and asset exposure is specified ([#50](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/50)).
- **Advisory lookup** lists indexed IDs with the same base when an exact tool or resource lookup misses. Request one of the listed IDs to retrieve that revision ([#51](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/51)).
- **KEV and ICS search pagination** points to the cursor on non-final pages and suggests a larger limit only below the per-call maximum ([#53](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/53)).
- **SSVC batch counts** echo all submitted IDs. SSVC and CVE status absence notices describe only the IDs processed ([#54](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/54)).
- **SSVC decision points** normalize recognized values from upstream and cached records. Unsupported Automatable or Technical Impact values preserve published evidence and explain why the timeline could not be computed ([#55](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/55)).
- **Vulnrichment lookups** propagate caller cancellation and report retryable fetch failures without exposing upstream exception text.
- **MCPB cleanup** preserves nested SDK skill runtime code while removing dependency documentation.
