# 0.4.0 — 2026-10-31

## Added

- Publish the CISA cybersecurity guide as an MCP skill resource.
- **`cisa_get_alerts`** continues after a GUID cursor within the available feed window; unavailable anchors return an empty page with restart guidance ([#46](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/46)).
- **Advisory applicability** retains product-scoped flags and impact statements, including unresolved group references ([#47](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/47)).

## Changed

- **Read inputs** accept up to 1,000 IDs or requested rows while retaining per-call workload caps, explicit batch remainders, and normalization telemetry; `CISA_CLAMP_OVERSIZED_INPUTS=false` rejects over-cap requests ([#41](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/41)).
- **Packaging** adds Agent Plugins root manifests and skill validation, strips development files from MCPB bundles, and preserves the mirror CLI scripts, SDK skill runtime, and SQLite prebuilts.
- **Development tooling** synchronizes framework references, uses a one-day minimum dependency release age, and classifies audit findings against the installed direct dependency version.

## Fixed

- **Grouped remediations** resolve product-group members into `productIds` while retaining verbatim `groupIds`; existing indexes re-ingest at content version 3 ([#43](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/43)).
- **KEV pagination** uses the current request's effective limit with the cursor's offset ([#44](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/44)).
- **Advisory outlines** retain identity, source URLs, and attribution on the tool and resource surfaces ([#45](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/45)).
- **SSVC batches** expose `outcome` and `failedCount`, separating failed fetches from confirmed absence in counts and guidance ([#48](https://github.com/cyanheads/cisa-cybersecurity-mcp-server/issues/48)).
